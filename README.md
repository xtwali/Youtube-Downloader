A high-performance YouTube downloader built using Tkinter and core Python libraries. Features an unmatchable download speed and a sleek graphical interface to save your favorite videos instantly. ⚡🚀

## Features
- **Unmatchable Speed:** Optimized stream fetching for maximum download speeds.
- **Sleek UI:** Clean and responsive interface built with Tkinter.
- **Easy Formats:** Download audio or video directly to your machine.

## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com.git
   cd Youtube-Downloader
   ```

2. **Install required dependencies:**
   ```bash
   pip install pytube customtkinter pillow
   ```

3. **Run the application:**
   ```bash
   python main.py
   ```
